# Platform profiles

Defaults for drafting. Each community changes its rules; read the current
ones before posting to Reddit, a forum or Hacker News. `docs/posts/VOICE.md`
overrides anything in this table.

| Platform | Marker | Length | Shape | Link | Hashtags | Tone |
|---|---|---|---|---|---|---|
| X | `x` | 280 characters per part | Single post or thread, parts numbered `1/`, `2/`; image on the part it illustrates | Last part, or the first reply | None unless VOICE.md says so | Direct, one point per part |
| LinkedIn | `li` | Up to 3,000 characters | First two lines show before "see more", so they carry the point; short paragraphs | First comment, not the body | At most three, only if VOICE.md allows | Plain; never "thrilled to announce" |
| Reddit | `reddit` | A few paragraphs | Self-post; check the sub's self-promotion rule and required flair | Only where the sub allows, usually in the body | None | Answer every comment; read the room first |
| Indie Hackers | `ih` | 300 to 800 words | A milestone or a lesson, with the numbers if VOICE.md allows sharing them | In the body | None | Honest about what did not work |
| Show HN | `hn` | Title plus a short first comment | Title `Show HN: <name>: <what it does>`; the first comment says how it works and what it does not do | The submission URL | None | Technical, understated, no marketing |
| Other forum | `forum` | Per the forum | Follow the forum's post format and category | Where the forum allows | None | Match the forum's register |
| Blog | `blog` | 600 to 1,500 words | Headings, code or output blocks, before and after | Inline | None | Explain the why, show the proof |
| Newsletter | `news` | 300 to 800 words | One topic, written to one reader, ends with what comes next | Inline | None | Conversational, no recap of everything |
| Facebook | `fb` | One to three short paragraphs | Image first, then the text | In the body | None | For a non-technical reader |
