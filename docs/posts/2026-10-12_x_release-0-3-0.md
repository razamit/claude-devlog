## English draft, not posted

1/ devlog 0.3.0 is out. It is a Claude Code plugin that keeps a project's progress log, decisions and tickets in plain markdown, and has Claude maintain them as it works. This release adds two skills: releases and posts.

2/ releases: every file that carries the version is listed once in docs/RELEASES.md. Drift between carriers and tags is flagged at every session wrap. Progress entries are stamped [unreleased] and flipped to the version at the cut, so the changelog is written from the entries.

3/ posts: a backlog of post ideas mined from the progress log, decisions and tickets, never from client email. One file per post per platform, holding the text as posted. A privacy gate runs before and after posting. Replies are folded back into tickets and decisions.

4/ Still plain markdown skills: no hooks, no scripts, no dependencies. This thread is the first post filed through the posts skill in the plugin's own repo.
