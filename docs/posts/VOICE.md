# Voice

Seeded 2026-10-12 from the user's own writing rules (global CLAUDE.md) and
the register of README.md and CHANGELOG.md, because no earlier posts
existed to paste. Provisional until the user confirms or edits it; the
`posts` skill reads it and never rewrites it silently. The five-question
interview below is still open.

- Language: Hebrew on X, with the technical nouns (devlog, skill, markdown, hooks, tags, changelog, file paths) kept in English; English drafts are a starting point, the user translates and reshapes before posting (first post, 2026-10-12)
- Person: first person singular for what I did; the plugin and its skills in third person
- Register: plain, technical, understated; a changelog bullet, not a launch
- Sentence shape: short, varied; one clause most of the time; no em dashes anywhere. On X, a single long post rather than a numbered thread
- Openers: the fact first (what shipped, what broke, what changed); never a question, never a tease
- Sign-offs: none; the last line is the link or the last fact
- Emoji: none
- Hashtags: none
- Never: revolutionary, game-changing, excited to announce, thrilled, journey, unlock, supercharge, seamless, "it's worth noting", stacked qualifiers; claims beyond the record
- Public about: clients none (this project has no client); revenue no; user counts no
- Sample as posted:
  > סקיל posts: מאגר רעיונות לפוסטים שנוצרים מיומן ההתקדמות, מההחלטות ומהטיקטים, אף פעם לא ממיילים של לקוחות. קובץ אחד לכל פוסט לכל פלטפורמה, עם הטקסט כפי שפורסם.
  > (from docs/posts/2026-10-12_x_release-0-3-0.md)
